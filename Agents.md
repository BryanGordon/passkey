# Proyecto
Sistema web en Astro para practicar el uso del login, consta unicamente de una pantalla de login y una pantalla de bienvenida despues de iniciar sesion. Datos de dos usuarios distintos almacenados en JSON local (`src/data/storage.json`)

# Comandos
+ `dev` para iniciar el proyecto.
+ `lint` para usar las reglas del linter.

# Estilos
+ Usa la ultima version de Astro.
+ Usar Typescript con la version 7.
+ Las varibles deben de estar declaradas en camell case.
+ El idioma de mensajes y texto dentro de las interfaces deben de estar en español.
+ Para el linter usar Eslint con la version 9.
+ Para las reglas del linter usar neostandard.
+ El estilo de las paginas deben ser modernos con colores azules y algun color complentario.

# Reglas
+ Lee `docs/constitution.md` y las specs correspondientes `docs/specs/` antes de realizar codigo a modificarlo.
+ No añadas dependencias innecesarias.
+ No uses colores genericos.
+ No optimices las paginas para responsive design.
+ No crees un usuario admin.
